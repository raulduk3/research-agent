Incoming requirement candidates

How to use this document. Each block below is a candidate requirement derived from a raw record, ranked against the specification for congruency and complexity. Read the blocks and discuss them. The page is static, so the file is edited in a text editor and committed like any document; the browser is for reading and for copying a block. When you decide a candidate is worth acting on, select the block, copy it, and paste it into an intake session. Nothing else reads this file, and nothing in it changes the specification until a decision is accepted.

Legend

Color marks congruency only, and the class name is always printed in the block. Complexity is the size badge. An easy patch is clarifies or amends at S. A hard change is amends or contradicts at L or XL.

  • already satisfied (gray): the specification already requires it.
  • clarifies (green): it sharpens an item without changing it.
  • amends (amber): it changes an existing item.
  • contradicts (red): it conflicts with an existing item.
  • brand new (blue): the specification is silent.
  • nonsense (muted, struck through): it cannot be acted on.

Kind is bug, amendment, feature or question. Complexity is S, M, L or XL, from the items touched, the files likely in scope, external provider effects and data migrations.

Candidate C-2026-09-19-223

Statement: A card SHOULD give, for the paper's nearest earlier neighbors, the outcomes that had resolved before the sheet's snapshot, and a nearest-neighbor forecast from them SHOULD answer every sheet as a baseline.

Kind: feature

Congruency: amends

Complexity: M

Spec items: SDD-RD-06, SDD-RD-08, SDD-IN-08, SDD-IN-09, SDD-AG-10, SDD-EN-04

Rationale: Reference-class forecasting by retrieval: papers like this one, and what happened to them. It needs no training and improves as the ledger fills, which is the cheapest way the system learns from outcomes. One card field over data the system already holds, and one more baseline beside SDD-IN-07 to SDD-IN-09. Leakage check: only neighbors that arrived earlier, and only outcomes whose resolution record predates the snapshot; a neighbor's unresolved horizons show nothing.
